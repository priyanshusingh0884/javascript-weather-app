# JavaScript Weather App 🌦️

A responsive weather application built using HTML, CSS, and JavaScript. It allows users to search for a city and retrieve its current weather information using the Open-Meteo APIs.

## ✨ Features

- Search weather information by city name.
- Geocoding API integration to retrieve geographical coordinates.
- Current temperature in Celsius.
- Relative humidity information.
- Wind speed information.
- Weather condition descriptions.
- Input validation for empty searches.
- Error handling for unsuccessful requests.
- Loading message while fetching weather information.
- Enter key support for searching.
- Handles outdated API responses to prevent incorrect results.
- Responsive user interface.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- Async/Await
- DOM Manipulation
- Open-Meteo Geocoding API
- Open-Meteo Forecast API

## 🌐 APIs Used

**1. Geocoding API**

Used to retrieve the latitude and longitude of a city.

**2. Weather Forecast API**

Used to retrieve current weather information, including temperature, humidity, wind speed, and weather code.
